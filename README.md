# Paradise Nursery Shopping Application

Paradise Nursery is a responsive React plant-shop application. Browse plants by category, add plants to a Redux-powered cart, update quantities, and view order totals.

## Features
- Landing page with company name and Get Started button
- About Us company information
- Categorized plant catalogue
- Add-to-cart and live cart count
- Redux Toolkit reducers: addItem, removeItem, updateQuantity
- Shopping cart with quantity controls, line totals, and order total
- Responsive layout

## Run locally
1. Install Node.js 18 or later.
2. Run `npm install`.
3. Run `npm run dev`.
4. Run `npm run build` for a production build.

## Technology
React, Vite, React Router, Redux Toolkit, React Redux, and CSS.
